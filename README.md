# Webアプリケーションテンプレート

このリポジトリは、モダンなWebアプリケーション開発のための基本的なテンプレートです。

## 機能

- 📱 レスポンシブデザイン
- 🚀 高速なパフォーマンス
- 🔒 セキュリティ対策済み
- 🌐 マルチブラウザ対応

## 技術スタック

- フロントエンド
  - React.js
  - TypeScript
  - Tailwind CSS

- バックエンド
  - Node.js
  - Express
  - PostgreSQL

## 始め方

1. リポジトリのクローン
```bash
git clone https://github.com/iokubotera7/test-repo.git
cd test-repo
```

2. 依存関係のインストール
```bash
npm install
```

3. 開発サーバーの起動
```bash
npm run dev
```

## 環境設定

1. `.env.example` を `.env` にコピー
2. 必要な環境変数を設定
